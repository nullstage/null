## AI-011 — 플레이어 스프라이트 파이프라인과 적용, 대시 연출

### 목적
도형(사각형)뿐이던 플레이어를 실제 도트 스프라이트로 교체하고, 대시·이동의 잔상 연출을 스프라이트 기준으로 재정비.

### 사용 도구
Claude Code + 외부 sprite-gen 파이프라인(codex 이미지 생성 → 마젠타 키잉 → 셀 정규화)

### 대표 프롬프트 (요지 재구성 — 원문 유실)
> 플레이어 스프라이트 시트를 만들어 적용하고, 걷기/점프/공격/대시 상태별 애니메이션과 대시 잔상을 붙여 달라.

### AI 제안 요약
- 64px 셀 시트 + manifest(행별 fps·frameDurations)를 정본으로 두고 `PLAYER_SPRITE` 상수로 옮겨 적음.
- 충돌 박스는 그림 전체가 아니라 몸통만(footY 기준 offset) — 억울한 피격 방지.
- 잔상은 복제 스프라이트 + 실루엣 tintFill + 가산 블렌드.

### 최종 반영
`Player.ts`(스프라이트 적용·애니메이션 상태기계·잔상), `types/combat.ts`(PLAYER_SPRITE), BootScene 로드·애니메이션 등록. WorkLog "플레이어 스프라이트 적용과 대시 연출" 참조.

### 사람의 수정 및 판단
- 도트 배율은 정수 유지(픽셀 격자 보호), 세부 수치(발끝 y 등)는 사용자가 화면 보며 확정.

### 관련 파일
`src/game/entities/Player.ts`, `src/game/types/combat.ts`, `src/game/scenes/BootScene.ts`

## AI-012 — UI 톤 통일 · Esc 일시정지 · 전투 연출과 셰이더

### 목적
React 패널들의 시각 톤 통일, 일시정지 메뉴 신설, 피격 셰이더·상시 조명 등 전투 화면의 분위기 강화.

### 사용 도구
Claude Code

### 대표 프롬프트 (요지 재구성 — 원문 유실)
> 패널 디자인 톤을 통일하고 Esc 일시정지 메뉴를 만들어 달라. 전투 화면에 피격 시 붉은 펄스와 캐릭터 중심 조명을 셰이더로 넣어 달라.

### AI 제안 요약
- 일시정지는 `game:pause`/`game:resume` 이벤트 쌍으로 모든 활성 씬을 멈추는 전역 처리.
- 셰이더는 게임 생성 시점에 파이프라인으로 등록(HitFx·AmbientLight), 씬은 세기만 조절.

### 최종 반영
`HUDOverlay.tsx`(Esc·ActivePanel 배타 상태), `PauseMenu.tsx`, `createGame.ts`(파이프라인 등록), `CombatVfx.ts`(pulseHitFx·attachAmbientLight). WorkLog "04:40 — UI 톤 통일 · Esc 일시정지 · 전투 연출과 셰이더" 참조.

### 사람의 수정 및 판단
- 붉은 펄스는 "내가 맞았을 때만" — 내 공격에도 화면이 반짝이면 피격 신호가 흐려진다는 피드백 반영.

### 관련 파일
`src/components/HUDOverlay.tsx`, `src/components/ui/PauseMenu.tsx`, `src/game/createGame.ts`, `src/game/systems/CombatVfx.ts`

## AI-013 — 방 1 전면 개편: 무전투 마을 + 전송 게이트 + 배경·타일·장식 파이프라인

### 목적
방 1을 전투 없는 마을로 바꾸고(DEC-013), 게이트 상호작용 진행·전용 배경(블러드문)·돌바닥 띠·장식 배치, 사용자 제공 시트의 마젠타 크로마키 분리 자동화.

### 사용 도구
Claude Code (+ 이미지 시트 크로마키 분리 스크립트)

### 대표 프롬프트 (요지 재구성 — 원문 유실)
> 방 1에서 적을 빼고 마을처럼 만들어 달라. 방 끝 게이트는 자동 접촉이 아니라 W(상호작용)로 넘어가게 하고, 넘긴 시트(기둥·아치·게이트)를 잘라 배치해 달라.

### AI 제안 요약
- 적 없는 방은 RoomController가 시작 즉시 클리어 처리 — 게이트 콜백만 채워 두는 구조 재사용.
- 게이트는 근접 시에만 머리 위 키캡 프롬프트 표시(반응 없는 버튼처럼 보이지 않게).
- 넓은 방(2560px)·카메라 lerp 추적·물리 월드 경계 동기화.

### 최종 반영
`CombatScene.ts`(buildStage 분기·게이트·프롬프트), `roomOneDecor.ts`, `combat.ts`(createArena 타일·배경 인자). WorkLog "방 1 전면 개편", "게이트를 접촉 트리거 → INTERACT 키로 변경" 참조.

### 사람의 수정 및 판단
- 계단식 발판은 사용자가 화면 확인 후 제거 결정. 접촉 트리거 → INTERACT 변경도 사용자 피드백.

### 관련 파일
`src/game/scenes/CombatScene.ts`, `src/game/data/roomOneDecor.ts`, `src/game/types/combat.ts`
