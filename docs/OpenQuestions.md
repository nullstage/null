# Open Questions

> 아직 확정되지 않은 정책·범위·기술 결정을 관리한다.  
> 구현을 막거나 결과에 영향을 주는 질문만 등록한다. 해결 후 상태를 `RESOLVED`로 바꾸고 관련 Decision ID를 연결한다.

## 상태 값

- `OPEN`: 결정 필요
- `BLOCKED`: 외부 확인 대기
- `RESOLVED`: 결정 완료
- `DROPPED`: 더 이상 결정할 필요 없음

## 임시값 규칙

뼈대 구현에 값이 반드시 필요하지만 아직 결정되지 않은 항목은 코드에 임시값을 두되,
해당 상수 옆에 `OQ-XXX 미결정` 주석을 남긴다. 임시값은 결정된 값이 아니며 상수 한 곳만 바꾸면 교체된다.

```md
| OQ-XXX | 결정해야 할 질문 | 선택지 A / B / C | 현재 권장안과 이유 | 기한 | OPEN | - |
```

## 처리 규칙

1. 구현에 영향을 주는 미결정 사항을 발견하면 이 문서에 등록한다.
2. 사용자 또는 팀이 결정하기 전까지 임의로 정책을 고정하지 않는다.
3. 뼈대 구현상 값이 필요하면 임시값을 쓰되 코드에 `OQ-XXX 미결정`을 남긴다.
4. 결정되면 `DecisionLog.md`에 근거와 대안을 기록한다.
5. 본 문서의 상태를 `RESOLVED`로 변경하고 Decision ID를 연결한다.
6. 범위나 계약이 달라지면 `MVP_PLAN.md`와 `Plan.md`도 함께 갱신한다.
