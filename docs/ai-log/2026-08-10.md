## AI-025 — 플레이어 스킬 이펙트 스프라이트화 + 슬롯형 액티브 스킬 시스템

### 목적

절차적 도형(Graphics)으로 그리던 검기·검극·검무 스킬 이펙트가 못생겨서 사용자가
외부에서 뽑아온 스프라이트로 교체하고, 늘어난 스킬(총·칼·대시)을 슬롯 등록·교체
구조로 정리하기 위해서다.

### 사용 도구

Claude Code (Sonnet 5)

### 대표 프롬프트

```text
지금 플레이어 스킬들 코드 다 보내줘 스킬 너무 못생겨서 스프라이트로 뽑아오게
```

```text
음… 그것보다 키 매핑으로 사용하는? 그런 스킬들… 저거 중에 하나로 선택해서
총 1개 칼 1개 대쉬 스킬. 하나씩 등록가능 그니까 만약 다른 스킬들 얻으면?
스킬 교체로… 이름이랑 설명은 너가 이미지보고 만들고
```

### AI 제안 요약

- 스프라이트 제작에 필요한 자세·프레임 목록을 먼저 정리해 사용자에게 전달, 사용자가
  외부 도구로 시트를 만들어 오면 코드에서 프레임 분해·재생 파라미터를 맞추는 분업.
- 스킬을 "칼/총/대시 슬롯 1개씩 + 획득 시 교체" 구조로 재편하고, 이름·설명 문구는
  사용자가 준 이미지를 보고 AI가 작성. 패링도 스프라이트 이펙트로 함께 교체.

### 최종 반영

- 검기·검극·검무 이펙트를 절차적 그래픽에서 스프라이트로 교체 (9765e45).
- 칼/총/대시 슬롯형 액티브 스킬 시스템 + 패링 이펙트 스프라이트화 (b3f3c88).
- 같은 새벽에 지역 진입 배너 추가(0a62bdf), 보스 체력바 정렬을 에셋 실측값으로
  교정(8f932c5)도 함께 진행했다.

### 사람의 수정 및 판단

- 스킬 후보 목록에서 "3번 제외하고 1,2번만 전부"처럼 어떤 스킬을 슬롯에 올릴지는
  사용자가 직접 골랐다. 스프라이트 에셋 자체도 사용자가 외부에서 제작해 공급.

## AI-026 — 라벨 서체를 네오둥근모로 교체

### 목적

보스 이름·지역명·아이템명 같은 게임 세계 고유명사 라벨의 서체를 도트 감성에 맞는
네오둥근모로 통일하기 위해서다. 대화(ChosunKg)와 메인 타이틀(이미지 로고)은 제외.

### 사용 도구

Claude Code (Sonnet 5)

### 대표 프롬프트

```text
보스 이름이랑 지역 이런 아이템들같은?? 대화 및 메인타이틀 제외한 폰트
네오둥근모로 해줄래?
```

### AI 제안 요약

- `@kfonts/neodgm`(OFL-1.1)에서 ttf만 내려받아 로컬 에셋으로 두고 `next/font/local`로
  로드 — npm 의존성으로 남기지 않음. 도트 폰트 특성상 `display: block` 사용.
- `theme.font.ui` 토큰(Pretendard였던 자리)을 바꿔 지역 배너·상태창·시작화면 메뉴가
  자동으로 따라오게 하고, Phaser 캔버스에 하드코딩된 Pretendard 5곳도 함께 교체.

### 최종 반영

- 94b55ad로 커밋. 이후 결과 화면 프레임 타이틀에도 같은 서체 적용(884de3f에 포함).

### 사람의 수정 및 판단

- 결과 화면 서체를 고를 때 "네오 둥근모로…"라고 사용자가 재확인. 단, 시작 화면
  메뉴는 이날 저녁 사용자 결정으로 다시 Pretendard로 되돌렸다(AI-031 참고).

### 관련 파일

- `src/styles/fonts.ts`, `src/styles/theme.ts`, `src/assets/fonts/NeoDunggeunmo.ttf`
- `src/game/entities/Boss.ts`, `src/game/scenes/BossScene.ts`

## AI-030 — 보스 판정·이펙트 정렬 버그 일괄 수정 (attackY 도입)

### 목적

보스를 2배로 키운 뒤 공격 판정과 이펙트가 전부 위로 떠서, 플레이어 스킬과 보스
이펙트가 타일 아래로 떨어져 보이고 바닥의 플레이어가 안 맞는 문제를 근본 수정하기
위해서다.

### 사용 도구

Claude Code (Sonnet 5)

### 대표 프롬프트

```text
아니 내스킬포함 아래로 떨어진다니까 ? 타일 밑으로 .. 보스도 그렇고
```

```text
스킬 하나씩 테스트하게 알려줘
```

### AI 제안 요약

- 원인: 2배 스케일로 `sprite.y`(원점)가 가슴 높이로 올라가 모든 공격 y좌표의 기준이
  어긋남. 증상별 오프셋 보정 대신 스프라이트 바닥 기준 `attackY` 게터를 도입해 모든
  패턴(SLASH·BARRAGE·CHAIN_PULL·DASH·WHIP)의 기준점을 단일화.
- 셀 기반 이펙트 시트는 프레임마다 바닥 접점이 달라 bottom-anchor origin offset으로
  정렬. 화면을 가로지르던 투사체 패턴은 손에서 제자리로 휘두르는 사슬(WHIP)로 재설계.
- 그림자(dormant) 상태의 idle·호흡·bob 흔들림을 전부 제거해 완전 정지.
- 스킬을 하나씩 강제 발동하는 디버그 콘솔 명령을 제공해 사용자가 패턴별로 검증.

### 최종 반영

- 이펙트 크기·바닥 정렬·히트박스·레이어 순서·지역 배너 위치 수정 (21e2376).
- attackY 도입, 이펙트 원점 보정, 사슬 휘두르기, 그림자 정지 (3e0bc70). 배포 완료.
- SLASH 패턴 직접 타격 테스트로 판정 복구 확인(보스 HP 999999→999979, 20 데미지).

### 사람의 수정 및 판단

- DevTools 콘솔 경고(allow pasting)로 디버그 코드 붙여넣기가 막힌 것을 안내받아 해결.
- "보스방 BGM이 두 개 나온다"는 제보는 사용자가 페이지를 두 개 띄운 착오로 판명 —
  코드 수정 없이 종결.
- 판결진·내려찍기 이펙트 높이는 배포 후 사용자 재검증이 남아 있다.

### 관련 파일

- `src/game/entities/Boss.ts`, `src/game/systems/CombatVfx.ts`
- `src/game/scenes/BossScene.ts`

## AI-031 — 세션 이전 + 타이틀 폰트 Pretendard 복귀 + 디버그 좌표 표시

### 목적

작업 폴더가 iCloud 밖(`~/dev/null`)으로 이전되면서 Claude Code 세션도 새 경로로
옮기고, 시작 화면 메뉴 서체를 Pretendard로 되돌리고, NPC 배치 좌표를 게임 안에서
바로 읽을 수 있게 디버그 좌표 표시를 붙이기 위해서다.

### 사용 도구

Claude Code (Fable 5)

### 대표 프롬프트

```text
오늘자 대화 내용 확인하고 ai log 작성해주고, 타이틀 폰트는 pretendard로 부탁해.
그리고 디버깅 모드 되어있으면 내 좌표 뜨게 해줘. npc 위치좀 옮기게
```

### AI 제안 요약

- 옛 세션 디렉터리의 파일 메모리를 새 세션 디렉터리로 이전.
- `theme.font`에 `title` 토큰을 추가(AI-026에서 네오둥근모로 바뀌었던 시작 화면
  메뉴만 Pretendard 스택으로 복귀). globals.css의 CDN 서브셋이 `Pretendard Variable`로
  선언되는 점을 반영해 스택 첫 항목을 맞춤.
- `?debug=1`일 때만 CombatScene·BossScene 좌하단에 플레이어 월드 좌표(`sprite.x/y`)를
  매 프레임 표시 — NPC 스폰 좌표와 같은 기준이라 그대로 옮겨 적으면 된다.

### 최종 반영

- `theme.font.title` 신설, TitleScreen 메뉴에 적용.
- 두 씬의 debug 블록에 좌표 텍스트 추가. `npm run build` 통과.

### 사람의 수정 및 판단

- "타이틀 폰트"의 범위를 시작 화면 메뉴로 한정(메인 로고는 이미지라 서체와 무관,
  라벨 서체 네오둥근모 결정은 유지).

### 관련 파일

- `src/styles/theme.ts`, `src/components/ui/TitleScreen.tsx`
- `src/game/scenes/CombatScene.ts`, `src/game/scenes/BossScene.ts`
