  대가로 대시 모션이 얌전해졌다. 밋밋하면 스프라이트가 아니라 속도·잔상 쪽에서 보완한다.
- **새 연출·새 스프라이트의 실플레이 확인은 사람이 해야 한다.**
  자동화 탭이 백그라운드로 내려가면 `document.hidden`이 true가 되어 `requestAnimationFrame`이 멈춘다.
  Phaser `update`가 안 돌아 키 입력이 처리되지 않는다.
  개발 빌드 전용 `?fast=1`(로딩·타이틀·프롤로그 건너뛰고 즉시 전투)로 진입까지는 우회했다.
  다만 fast를 켜면 일시정지의 「나가기」가 시작 화면에서 멈추지 않는다. READY가 되는 즉시 재시작하기 때문이다.
- 전투 수치가 아직 `Player.ts`의 `TUNING`과 `CombatVfx.ts`의 `VFX`에 나뉘어 있다.
  확정되면 `gameBalance.ts`로 옮긴다. (OQ-007)

### 착지 직후 바닥 아래로 훅 꺼지는 버그 수정

- 상태: DONE (코드 원인 확정, 새로고침해도 재현된다는 사용자 확인으로 HMR 잔재 가능성 배제)

  Phaser Arcade `Body.updateFromGameObject`가 매 프레임 `height = sourceHeight * scaleY`,
  `position.y = ... + scaleY * offset.y`로 충돌 박스를 다시 계산한다(소스 직접 확인).
  접지 상태에서 `scaleY`를 순간적으로 줄이면 박스 바닥이 바닥면 위로 살짝 뜨고,
  다음 프레임 중력이 그 틈만큼 다시 끌어내려 "훅 꺼졌다 다시 붙는" 것처럼 보였다.
  점프 이륙 펀치(`scaleY` 증가)는 반대 방향이라 몸이 이미 위로 뜨는 중이라 안 보였다 —
  착지 펀치(`scaleY` 감소)만 유일하게 문제였다.

#### 수정

- `Player.onLand()`의 `punch(1.16, 0.86)`를 제거하고, 물리에 관여하지 않는 카메라 흔들림
  (`landShakeMs: 70`, `landShakeIntensity: 0.004` — 전투 흔들림보다 약하게)으로 대체.
  흙먼지(`groundDust`)는 그대로 유지.
