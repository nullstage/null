1. **실플레이 검증.** 전투가 붙었지만 아직 사람이 플레이해 본 적이 없다. 조작감·타격감이 먼저다.
2. 밸런스 조정. 각 파일 상단에 흩어진 임시 수치를 `gameBalance.ts`로 모은다.
3. 점프 높이 확인 (OQ-007). 중력 1400 / 점프 520이면 최고점 약 96px로, 투사체 회피에 빠듯할 수 있다.
4. F2 스킵 없이 전체 런을 관통한다.
5. 실제 적중 데이터로 RANGED/MELEE 분류가 카운터 방 구성으로 이어지는지 확인한다.
6. Day 2 전에 OQ-009~013(Director 정책)을 결정한다.
